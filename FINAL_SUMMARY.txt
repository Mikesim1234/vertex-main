STEP 1: INSTALL DEPENDENCY (2 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Run ONE of these commands:

Using npm:
  npm install nodemailer @types/nodemailer

Using pnpm:
  pnpm add nodemailer @types/nodemailer

Using yarn:
  yarn add nodemailer @types/nodemailer


STEP 2: CREATE .env.local (3 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Create a NEW file called .env.local in your project root with:

  SMTP_HOST=smtp.gmail.com
  SMTP_PORT=587
  SMTP_USER=michaelmaguke@gmail.co.ke
  SMTP_PASS=YOUR_GMAIL_APP_PASSWORD_HERE
  CONTACT_RECEIVER_EMAIL=michaelmaguke@gmail.co.ke

FOR GMAIL USERS - Get App Password:
  1. Go to https://myaccount.google.com/apppasswords
  2. Select "Mail" and your device type
  3. Google generates 16-character password
  4. Copy it (remove spaces if present)
  5. Paste into SMTP_PASS above

⚠️  IMPORTANT: Never commit .env.local to Git
    It's already protected by .gitignore


STEP 3: TEST LOCALLY (5 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Start dev server:
  npm run dev

Open in browser:
  http://localhost:3000/#contact

Fill out form:
  - Full Name: "Test User"
  - Email: "test@example.com"
  - Message: "This is a test"

Submit form

Check results:
  ✓ Form shows success message
  ✓ Check inbox at michaelmaguke@gmail.co.ke
